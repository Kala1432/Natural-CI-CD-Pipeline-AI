# Tables

## users

Purpose

Stores application users.

Columns

- id
- username
- email
- password_hash
- created_at
- updated_at

Relationships

One User

↓

Many Repositories

Many GitHubAccounts

Many GeneratedWorkflows

---

## github_accounts

Purpose

Stores GitHub OAuth credentials.

Columns

- id
- user_id
- github_user_id
- username
- access_token
- refresh_token
- expires_at

Relationship

Many-to-One

↓

User

---

## repositories

Purpose

Stores synchronized GitHub repositories.

Columns

- id
- user_id
- github_repo_id
- name
- full_name
- default_branch
- visibility
- language
- stars
- forks
- updated_at

Relationships

Repository

↓

Many Branches

Many Workflows

Many PipelineExecutions

---

## branches

Purpose

Repository branches.

Columns

- id
- repository_id
- name
- last_commit_sha

---

## workflows

Purpose

Discovered GitHub workflow files.

Columns

- id
- repository_id
- workflow_name
- workflow_path
- github_workflow_id

---

## generated_workflows

Purpose

Workflow files generated by Pipeline.sh.

Columns

- id
- repository_id
- user_id

- git_ref
- generated_at

---

## pipeline_executions

Purpose

Stores workflow executions.

Columns

- id
